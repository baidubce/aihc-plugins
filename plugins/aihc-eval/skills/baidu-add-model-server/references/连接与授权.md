# 连接与授权

**产出状态变量**：`SSH_CMD`、`SSH_AUTHORIZED`、`CONN_MODE`、`SSH_TARGET`、`SSH_PORT`、`SSH_KEY_PATH`。

## Phase 1 收集（步 1）

缺地址时在 G1 问**开发机的公网访问地址**——`<host>:<port>`（公网 IP 或域名 + SSH 端口）。
拿到地址后补齐登录方式，拼成一条基础 SSH 命令 `ssh -p <port> -i <key_path> <user>@<host>`
（没有私钥就省掉 `-i`，用户名默认 `root`——这是标注不单独问，在 G2 回显里标 `假设：`；给的不是 root 按「改变任务性质」停，不进 G2）。用户若直接给了整条 SSH 命令，
就从里面解析地址，不再重复问。

**只给了 host 没给 port 时按 SKILL.md 步 1 取端口，不要默认 22**。

命令里若含远端命令、管道、分号、换行、重定向，先规范化成只有连接参数的形态；
无法安全规范化就让用户重新给。拼好的命令**不单独确认**：直接做 Phase 2 的本地 TCP 探测，
把命令（私钥只显示路径）与探测结果一起放进 G2 回显——用户在 G2 选「重输」即回到这里。

## Phase 2 连通性测试 + 授权（步 2）

顺序是「先探端口、再要授权、最后验登录」，不得颠倒。

1. **本地 TCP 探测**（不登录、不碰私钥，不算远端执行，可直接跑）：
   ```bash
   nc -z -w 5 <host> <port> && echo "tcp open" || echo "tcp unreachable"
   ```
   没有 `nc` 时退化为 `curl -s --connect-timeout 5 -o /dev/null telnet://<host>:<port>`（rc=0 即通）。
   端口不通 → 不进授权，按 SKILL.md「出错」格式报（卡在步 2 / 开发机零写入），选项（不标推荐）：不确定，先停 / 原地址重探（至多 2 次，用满后不再给这一项；重输相同的 host:port 不重置计数）/ 重输地址 / 取消。
2. **取 SSH 授权 = G2**（必须用 `AskUserQuestion`，题干带回显的 SSH 命令 + `tcp open`，第一项推荐）：
   1. 授权连接并远端执行（推荐）→ `CONN_MODE=remote_exec`、`SSH_AUTHORIZED=true`
   2. 只生成命令不执行 → `CONN_MODE=dry_run`、`SSH_AUTHORIZED=false`
   3. 重新输入地址 / SSH 命令 → 回 Phase 1
   4. 取消 → `CONN_MODE=cancelled`，结束

3. **登录验证**（仅 remote_exec，授权之后才做）：
   `<SSH_CMD> -o StrictHostKeyChecking=accept-new -o BatchMode=yes "echo connected"`（`StrictHostKeyChecking=accept-new` 直接并进 `SSH_CMD`，G2 回显的命令就带上它，与实际执行的不留差异；报 host key 变更时提示 pod 重建，给 `ssh-keygen -R "[<host>]:<port>"`，选项为「不确定，先停 / 重试（已执行）/ 只生成命令 / 取消」（「重试」只给 1 次，再报变更就撤掉这一项、换回「重输」），不当瞬断重试），
   输出含 `connected` 且退出码 0 才算过。失败先静默重试 1 次；仍失败再给一次
   「不确定，先停 / 重输 / 只生成命令 / 取消」（不标推荐；重试上限已用完，不再给「重试」），并按现象提示：

| 现象 | 提示 |
|---|---|
| `Permission denied` | 检查私钥路径、用户名、开发机授权 |
| `Connection timed out` / `No route to host` | 检查开发机状态、端口、安全组、网络 |
| `BatchMode` 导致失败 | 只有私钥带口令时提示 `! ssh-add <key>`；密码登录不支持，提示改用密钥登录，不给无效的「先交互登录」 |

命令带跳板机（`-J` / `ProxyJump`）时对完整命令做检查，失败要区分跳板机不可达与目标不可达。

## Phase 3 执行纪律（贯穿全程）

- 用户未授权前不得执行任何远端命令；`dry_run` 下只输出命令，一条都不执行。
- 远端多行脚本一律 heredoc：`<SSH_CMD> -o BatchMode=yes 'bash -s' <<'REMOTE' … REMOTE`；
  不对 `SSH_CMD` 用 `eval`。远端激活脚本可能读未定义 `PYTHONPATH`，heredoc 开头先
  `export PYTHONPATH="${PYTHONPATH:-}"`。
- 只读命令（体检、查看日志、`ls`）G2 授权后直接跑，不再问；写与删的批准见 SKILL.md 步 6、阶段 6。
- 不读取、不打印、不上传私钥；不回显 token / AK/SK；dump `/proc/1/environ` 时要过滤掉凭据类键。
