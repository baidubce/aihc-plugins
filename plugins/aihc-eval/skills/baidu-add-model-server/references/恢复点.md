## PROGRESS

每行 `<类型>\t<内容>\t<时间>`，只追加不改写。**步骤行** = 每过一个停点写的 `<步>\t<结论>`，
定位只看步骤行；恢复时重过的 G2 记 `reauth\t<remote_exec|dry_run>`，不算步骤行，只按取值认。下表里只有 G4 行（含 `沿用原批准`/`dry_run 自跑`）算步骤行，最后一条步骤行是 G4/G5 行即「在步 7」。
**批准类 G4** = 用户点选的 G4 行，不含这两种。`G4\t作废`（作废已点选、其后无 `rm done` 与 `started` 的 G4 时写）与它之前最后一条批准类 G4 在各口径里都不认（不算步骤行/G4 行、不收口 `rollback→`）；最后一条 G4 类行已是 `G4\t作废` 时不再追加。

| 行 | 何时写 | 怎么认 |
|---|---|---|
| `G4\t沿用原批准` / `G4\tdry_run 自跑\t<name>` | 回退收口且差量 G4 为「否」/ dry_run 产物核过 | `dry_run 自跑` 之后 L1 FAIL 不自修，回步 6 摆 G4 |
| `setup\tstarted\t<name>` | 发起远端启动**之前** | 只认最后一条 `started` 及其后的 `setup` 行 |
| `setup\textend` | 超时后选「再等」、`killed` 后选「接着等」，或 auto 自动续等 | 超时预算从最后一条 `started`/`extend`/`reauth` 起算（不跨会话） |
| `setup\tkilled` | kill **之前** | 已停（见第 3 步）且无 `EXIT=`、其后无 `rollback→`/`rename→` 时不当终态、不自修：摆「不确定，先停 / 整份重跑 `setup.sh` / 回 G3 改值」，不标推荐；其后有 `revive` 的把「整份重跑」换成「重摆全量 G4」 |
| `setup\texit=0` | `EXIT=0`、`SETUP_OK` 与 `ls` 复核都过之后 | 见第 3 步 |
| `L1\t<b>\tn/n` | 阶段 5 两道门禁与人工三项都过后 | 早于最后一条 `started` 或 `stop\t7\tG4 后改 dry_run` 的不算 |
| `L1-post-clean\t<b>\tn/n` | 阶段 6 清理后复跑 | 只认最后一条 G4（含 `沿用原批准`）、`started`、G5 与 `G4 后改 dry_run` 停之后的 |
| `selfrepair\t<b\|setup>\t<n>` | 每次自修 | 只认最后一条批准类 G4 之后的（`stop\t7\tL1 自修用尽` 之后重摆的不算起点）；经 G3 改值后追加 `<b>\t0`；计划内重跑（`rm done` 后、回退后）与端口被占用不计 |
| `rm done` | 差量 G4 的 `rm` 执行后 | 只认最后一条批准类 G4 之后的；差量 G4 含 `rm` 而没有它就不重跑 `setup.sh` |
| `rollback→<步>\t<原因>` | 任何回退；步 8 之后的任何远端写动作**之前**（删 `authorized_keys` 除外，只记它自己的行） | 见「收口」 |
| `rename→<新>\t<旧>` | 旧 setup 出 `EXIT=` 或已 `killed` 且已停之后 | 见 `改主意回退.md`「改名」 |
| `step8 written` | 写完 `$W/STEP8`、输出高亮块之前 | 半交付判定 |
| `authorized_keys\t<删\|删 done\|留>` | 摆去留问前先记 `留`；`删` 执行前记，rc=0 追加 `删 done`（不再登录验证），rc≠0 写 `stop\t8\t公钥未确认已删` 给终态「勿保存镜像」；交付后才删同样走，并提醒「已存的镜像要重新保存」 | 只认最后一条 |
| `step8 delivered` | `authorized_keys` 行之后 | 交付判定 |
| `obsolete→<host>_<port>` / `revive` | 换机时写在旧机目录 / 回到旧机时 | 候选判定 |
| `stop\t<步>\t<原因>` | 给出取消、只要报告、G4 后改 `dry_run`、超时选「看 tmux / 取消」、「停在当前步」、L1 自修用尽、5d 硬失败、L3 先停这类终态时 | 候选判定，只认最后一条（恢复中重过 G2 或选目录收敛停下的不另写；第 2、3 步明写的照写）；接回时重摆所记步的问（1→G1，2–5→并进第 3 步那次 G2 后按第 4 步分支表自上而下走，6/7 先按第 3 步重过 G2，6→重跑 5d 后摆 G4，7→依次：`G4 后改 dry_run` 按 `改主意回退.md`；最后一条 `started` 之后无 `exit=0` 按第 3、4 步定位；G5 选「不清理」的重摆 G5；`L1`（或 G5 之后的 `L1-post-clean`）缺项给出错块，`需要你：` 同 SKILL.md「出错」G4 内可修行；都齐则无 G5 摆 G5、有则进步 8；8→按第 2 步半交付判定），其余不按分支表跳过 |

### 收口

- 定位按最后一条 G4 行之后**全部未收口**的 `rollback→` 里最靠前的步，不按最后一条。
- 必重跑门禁过后（要重跑 setup 的以 `exit=0` 为准）收口：差量 G4 为「是」由新 G4 行收口，为「否」补 `G4\t沿用原批准`；最后一条 G4 行是 `dry_run 自跑` 时不补，回步 6 摆全量 G4。
- `rollback→阶段6`（G5 补删也写它）由其后全部 benchmark 的 `L1-post-clean` 加新的 `step8 written` 收口，不重跑 setup。
