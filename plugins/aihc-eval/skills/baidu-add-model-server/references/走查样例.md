# 一键走查样例（G1 → G5 → 步 8）

> 用一台假想机把八个停点串成一条链路，给首次执行者对顺序与输出形状的直觉。
> **样例里的值全是假的**（`1.2.3.4:8181` / `dm05` / `/mnt/pfs/models/DM05`），照抄会错机；
> 规则以 `SKILL.md` 与 `交互守则.md` 为准，本文只演示「先发生什么、后发生什么」。

---

## G1（步 1）：开始前对齐

用户：`把 /mnt/pfs/models/DM05 做成 RoboDojo 的 MS，机器 ssh -p 8181 root@1.2.3.4`

①④ 都在用户消息里 → **不停，直接进步 2**（G1 没有缺项就不摆）。

> 反面：用户只说「把 DM05 接进评测」——缺 ④，摆 `AskUserQuestion`（`multiSelect: true`），
> 选项取 SKILL.md 5a 表；④ 里只认本次会话说过的或 `$W/form.yaml` 已有的，记忆里别的模型用过的 benchmark 不静默采用。

## G2（步 2）：TCP 探测 + 授权

```text
TCP 1.2.3.4:8181 可达（nc -z 通过）
SSH 命令：ssh -p 8181 root@1.2.3.4      # 私钥：无（走 agent），不显示密钥内容
假设：SSH 用户 root（未指定）
```
`AskUserQuestion`：授权执行（推荐）/ 只生成命令 / 重输 / 取消

选 1 → 才跑 `echo connected`。选「只生成命令」→ 输出步 3 体检与 5b probe 的完整命令，请用户贴回；
不贴回或两次无效即以 `dry_run` 终态收口并写 `stop\t2\tdry_run`。

## 步 3–4：只读探测（不问人）

`✓ 环境探测完成：无 ray、有 Python 3.13.12、ckpt 在挂载盘、根盘可用 46 GiB、无凭据落盘 → 接下来 预填表单并一次确认`

判档结论**不单开一问**，并进 G3 的第一块。

## G3（步 5）：判档 + 预填表单，一次确认

```text
环境探测结果（只读，未做任何改动）
| 项 | 现状 | 满足 | 不满足的后果 |
| PATH 上第一个 ray | 无 | ✗ | KubeRay 只认它 → 任务等满 600s 报「MS 节点不足」 |
| Python 3.13.12 | 无（有 3.11） | ✗ | 版本不一致连不上 GCS，不报版本错 |
| 其余已满足 | /usr/local/bin 可写 / 模型环境 conda dm05（torch 2.6）/ ckpt 挂载盘 / 根盘 46 GiB / 无凭据 | ✓ | — |
判档: 重档：需补装 Ray 解释器，需外网
```
紧跟 YAML（每行带 `# [探测] <出处>` 或 `# [待填]`）、`假设：` 块，然后**一次** `AskUserQuestion`：
表单（采用预填值（推荐）/ 改某几行 / 只要报告不改造）+ probe ckpt（仅当 ③ 是探到的）+ L3 缺项 + `ckpt_mode`。
L3 与 probe ckpt **不标推荐**、第 1 项「不确定，先停」；`sample_action` 不进选项，缺了写进 `假设：`。

## 步 5d：改造前置检查（不问人，结论进 G4）

`/etc/uv/uv.toml` 未钉 `cache-dir` → **硬失败**，立刻停：`需要你：` 给「不确定，先停 / 重探 / 取消」+ 可直接粘贴的修法。
`/opt/ms-dm05` 已存在 3 个文件 → 计划里标「覆盖 /opt/ms-dm05`（现有 3 个文件、`setup_sha256=…`）`」，G4 按含覆盖形态摆。

## G5（阶段 6）：清理清单

只列不删 → `AskUserQuestion`：按清单全删（推荐）/ 先看逐项 / 剔除某几项（私钥、凭据、代理行、history 不可剔除）/
